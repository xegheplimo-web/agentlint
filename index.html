AgentLint

An open agentic website that audits other agentic websites.

Audit a site

Paste the address of an agentic website — the folder that should hold agent-manifest.json. AgentLint fetches it and its published network files, checks them against the Open Agentic Web MVP 0.2 minimum, and shows exactly what it found. A CORS failure is a finding, not an error to hide; a check that cannot run is reported as skipped, never as a pass.
